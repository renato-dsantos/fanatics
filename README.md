# Fut Fanatics

Protótipo SSR do MVP para acompanhar o Brasileirão Série A de 2026. A implementação atual usa Node.js nativo, EJS e dados demonstrativos fictícios; não apresenta classificação oficial nem integra uma fonte esportiva.

## Executar

Requer Node.js 20 ou superior.

```sh
npm install
npm start
```

Acesse `http://localhost:3000`. Use o filtro para abrir a campanha demonstrativa de um clube.

## Testes

```sh
npm test
```

Veja [a arquitetura](docs/prd/arquitetura.md) para os limites do protótipo, decisões atuais e componentes planejados.
